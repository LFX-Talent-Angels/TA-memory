## Rules (summary)

- This repo is the **permanent record**: proposals, decisions, meeting notes,
  learnings, timeline. It is append-mostly — add, don't rewrite.
- **No personal data** (no CVs / cover letters / anything from `Mentees/`).
- Mirror accepted ADRs here from `TA-workspace/docs/decisions/`.
- Branch + PR flow, every commit DCO signed-off (`git commit -s`). Never push to
  `main`. No secrets.
