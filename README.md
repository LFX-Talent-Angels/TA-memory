# TA-memory

> The **project memory** of Talent Angels — why it exists and how it evolved.

Part of the [`LFX-Talent-Angels`](https://github.com/LFX-Talent-Angels) org. For
project-wide docs and rules, see
[`TA-workspace`](https://github.com/LFX-Talent-Angels/TA-workspace).

This repo is the permanent, append-mostly record that gives context to future
mentees and AI coding agents. Content is **CC-BY-4.0**.

## Contents

| Folder / file                                  | What it holds                                       |
| ---------------------------------------------- | --------------------------------------------------- |
| [`proposals/`](./proposals)                    | The original project proposal and any revisions     |
| [`decisions/`](./decisions)                    | Accepted ADRs (mirrored from the workspace)         |
| [`meetings/`](./meetings)                      | Meetup and sync notes                               |
| [`learnings/`](./learnings)                    | Non-obvious insights, gotchas, dead-ends            |
| [`timeline.md`](./timeline.md)                 | Chronological project log                           |
| [`team.md`](./team.md)                         | Opt-in, self-written team page (mentors + mentees)  |

## Start here

👉 [`proposals/original-proposal.md`](./proposals/original-proposal.md) — the
source of truth for the project's scope and intent.

## Ground rules

- **Append-mostly.** Add to the record; don't rewrite history. Correct with a new
  dated note.
- **No personal data.** Never store CVs, cover letters, or anything from the
  local `Mentees/` folder.
- Date entries `YYYY-MM-DD`.
