# Team

Talent Angels is built by mentees and mentors under LF Decentralized Trust.

This page is **opt-in and self-maintained**. Add *yourself* with a Pull Request —
it doubles as your first Git exercise. Share only what you're happy to make
public. **Do not** add anyone else's details, and never copy anything from a CV,
cover letter, or other private document.

## How to add yourself

1. Branch, edit this file, add one row to the Mentees table.
2. Include: your name (as you want it shown), your GitHub handle, and a one-line
   focus/bio **you write yourself**.
3. `git commit -s` (DCO), open a PR, request a mentor review.
