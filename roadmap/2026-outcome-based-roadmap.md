## Product vision

In the next 3 years, Talent Angels will be the leading open-source suite of AI
Graph Agents for skills, tasks and occupations — the unified GraphRAG reasoning
layer bridging human talent development and AI-driven work.

**2026 program goal (26-week mentorship):** ship a working GraphRAG agent suite —
Locator, Connector and Pathfinder — validated in live university courses in El
Salvador and Mérida, México, feeding the Learning Tokens Proof-of-Learning (PoL)
layer by Week 26.

## Goals & objectives

1. **Unified reasoning layer** — a GraphRAG layer over the five taxonomies (ESCO,
   O*NET, SFIA, BLS, Lightcast) under one shared semantic framework.
2. **Three core agents** — ship Locator, Connector and Pathfinder through a
   natural-language chat interface over the talent knowledge graph.
3. **Real-world validation** — deploy with partner universities (UCA El Salvador,
   Mérida MX) and feed the Learning Tokens PoL layer at LFDT.

## The roadmap — NOW / NEXT / LATER

Only Sprints 1–2 are **committed**; beyond that the path is intentionally
provisional and refined each sprint. The agent milestones stay fixed as the
north star.

### NOW · COMMITTED · Sprints 1–2 · Weeks 1–4
- **Sprint 1 · Wk 1–2 — Foundations.** Understand knowledge graphs + define
  purpose & scope. The 5 taxonomies are modeled as a knowledge graph; use case,
  user needs, success criteria & constraints documented.
- **Sprint 2 · Wk 3–4 — Agent infrastructure.** Choose LLM + Tools & Integration
  + Memory System. Base model selected (params, context, cost/latency); taxonomy
  APIs wired; vector + structured memory operational.
- *Outcome: foundation laid for the agent suite.*

### NEXT · EMERGING · refined sprint by sprint
- **Locator agent** — pinpoint the exact position of any skill, task or
  occupation within the taxonomies via chat.
- **Connector agent** — list the nodes directly preceding & succeeding a location
  to explore related tasks and skills.
- **Supporting build** — system prompts, orchestration & chat interface shaped
  around the agents as scope firms up.
- *→ Locator & Connector agents live.*

### LATER · DIRECTIONAL · agent north star
- **Pathfinder agent** — discover learning journeys (all routes) between any two
  skills, tasks or occupations.
- **Evaluator agent (future)** — rank paths by relevance, distance & alignment
  with individual skill profiles.
- **Deploy & validate** — roll out to partner-university courses (UCA El Salvador,
  Mérida MX) and feed Learning Tokens PoL.
- *→ Pathfinder, then Evaluator.*
