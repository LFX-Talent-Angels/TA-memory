# Learnings

Non-obvious things we learned along the way: gotchas, insights, and dead-ends
worth remembering. One file per learning, named `YYYY-MM-DD-short-title.md`.

A good learning entry captures:

- **What** we expected vs. what actually happened
- **Why** it matters (the non-obvious part)
- **How to apply it** next time

This complements the per-agent "memory" concept in the project: when your AI
coding agent (or you) discovers something surprising, write it down here so the
next mentee doesn't relearn it the hard way.

> Keep it free of personal data and secrets.
